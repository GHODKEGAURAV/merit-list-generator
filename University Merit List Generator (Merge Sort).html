How the algorithm works

Divide: split the list in half until each part holds one student. Conquer: a single student is already sorted. Combine: merge two sorted halves by repeatedly picking the better student from the front of each half.

Merge sort is stable and always takes O(n log n), so it suits large merit lists better than bubble sort or insertion sort at O(n²).
